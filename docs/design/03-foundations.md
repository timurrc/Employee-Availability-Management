# 03. Визуальная основа и компоненты

Готовые токены — [`tokens.css`](./tokens.css): заменяет блок `@theme` в `src/index.css` целиком.

## Принципы визуального языка (B2B)

1. **Плоско и спокойно.** Нейтральная база (белый/графит + серые), без градиентов и стекла. Глубина — через `surface` (фон страницы) → `elevated` (карточка) и тонкие границы, тени — только у всплывающих слоёв.
2. **Один акцент.** `primary` — только главное действие экрана, активный пункт навигации, фокус, ссылки. Показатели и графики не красим акцентом.
3. **Цвет = смысл.** Семантика (`success`/`warning`/`danger`) — только статусы и риски. Типы отсутствий — отдельная категориальная палитра `abs-*`, не пересекается с семантикой.
4. **Цвет никогда не один.** Каждый тип/статус кодируется ещё иконкой и/или текстом, плановое — штриховкой. Таблица ниже — обязательна.
5. **Иерархия экрана:** действие → ключевое значение (кто отсутствует, дата, баланс) → детали → сводка.
6. **Плотность B2B:** базовый текст 14 px, строки таблиц 40 px, таймлайн 36 px. Цифры — `tabular-nums`.

Модификаторы (одинаково на всех типах):

- **Согласовано / действует** — сплошная подложка `*-bg`, левая граница 3 px `*`.
- **На согласовании / черновик** — та же подложка + штриховка `pattern-pending`, граница пунктиром, в подписи «(на согласовании)». Черновики видит только автор.
- **Открытый больничный (дата окончания неизвестна)** — полоса тянется до «сегодня + 3 дня» и растворяется (маска-градиент к прозрачному), на конце `?`; подпись «дата выхода неизвестна». Никаких выдуманных дат окончания.
- **Отклонено / отменено** — в сетке не рисуется; в списках — зачёркнутые даты + статус-бейдж.

## Статусы (бейджи)

Бейдж: высота 22 px, `radius-sm`, `text-sm` 500, иконка 14 px + текст, подложка `*-bg`, текст `*`.

| Сущность             | Значение → подпись → тон                                                                                                                                                                                                                              |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Доступность человека | на месте → «На месте» → success (только в карточке сотрудника; в списках не показываем — шум) · отсутствует → «{Тип} до 9 дек.» → цвет типа · скоро → «С 1 дек. — отпуск» → warning · открытый больничный → «Больничный, выход неизвестен» → abs-sick |
| Заявка на отпуск     | draft «Черновик» neutral · pending «На согласовании» info · approved «Согласована» success · rejected «Отклонена» danger · cancelled «Отменена» neutral                                                                                               |
| Больничный           | open «Открыт» abs-sick · extended «Продлён» abs-sick · closed «Закрыт» neutral                                                                                                                                                                        |
| Этап согласования    | waiting «Ожидает» neutral · in_progress «На согласовании» info · approved «Согласовано» success · rejected «Отклонено» danger                                                                                                                         |
| Риски                | «Риск срока» warning · «Нет замещающего» danger · «Ниже порога» danger · «У порога» warning                                                                                                                                                           |

Шрифт Geist (подключить `@fontsource-variable/geist`, fallback system-ui), моноширинный — только номер ЭЛН и номер документа.

| Роль                                   | Токен       | Размер / вес      |
| -------------------------------------- | ----------- | ----------------- |
| Заголовок страницы                     | `text-xl`   | 24 / 600, −0.01em |
| Заголовок карточки/секции              | `text-md`   | 16 / 600          |

## Формат дат и чисел

- В интерфейсе — `date-fns` + `ru`: «9 дек.», «9 дек. 2026» (если год ≠ текущему), периоды «1–14 дек.», «28 дек. – 13 янв.» (тонкий пробел вокруг тире при разных месяцах).
- Относительность — только для ближайшего: «сегодня», «завтра», «через 3 дня». Дальше — дата.
- Окончание отсутствия всегда как **последний день отсутствия** («в отпуске до 9 дек. включительно») + отдельно «выйдет 10 дек.» в карточке.
- Дни: «14 дн.» в таблицах, «14 календарных дней» в форме. Различать «календ.» и «раб.» везде, где они могут спутаться.

## Сетка и каркас

- Десктоп ≥ 1280: сайдбар 240 px + контент, макс. ширина контента 1200 px (кроме Календаря команды — во всю ширину).
- Планшет 768–1279: сайдбар свёрнут до 64 px (иконки + тултипы), раскрывается поверх.
- Мобильный < 768: топбар 56 px с бургером, навигация — выезжающая панель; таблицы превращаются в списки карточек; Календарь команды — режим «список по дням».
- Отступы: шаг 4 px; между секциями 24, внутри карточки 16, поле страницы 24 (мобильный 16).

## Иконки

lucide-react, 16 px в тексте и кнопках, 20 px в навигации, stroke 1.75. Иконка без подписи — только с `aria-label` и тултипом.

## Доступность

- Контраст AA для всего текста, 3:1 для границ полей и фокуса.
- Сетка таймлайна — `role="grid"`, ячейка объявляет «Иванов И., 9 декабря: отпуск, согласован». Навигация стрелками.
- Статусы не только цветом (см. таблицы).
- Тосты не отбирают фокус; модалки — ловушка фокуса, `Esc`.
- `prefers-reduced-motion` — анимации отключены (в `tokens.css`).
- Минимальная цель касания 40×40 на мобильном.

## Тон текстов

Коротко, по делу, без канцелярита и без «Упс!». Что произошло → что делать. Пример: «Смирнов тоже в отпуске до 12 дек. — замещает Козлов». Ошибка: «Не удалось сохранить заявку. Данные не потеряны — повторите». Пустые состояния называют хорошую новость, если она есть: «Все на месте».
