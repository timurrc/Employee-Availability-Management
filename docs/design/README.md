# Дизайн: «Доступность» — модуль доступности сотрудников для СЭД

Источник для чата вёрстки. Перед вёрсткой экрана открой его файл в `screens/`; общие правила — в `03-foundations.md`, токены — `tokens.css`.

**Ключевой вывод:** сотрудник в штате ≠ сотрудник, который может подписать сегодня. Поэтому статус доступности и заместитель видны везде, где есть имя человека (`PersonChip`), а любой срок показывается датой с разбором.
