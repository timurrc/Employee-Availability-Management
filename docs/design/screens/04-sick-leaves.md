# 04. Больничные (HR)

Код: `src/pages/SickLeavesPage`. Роут `/sick-leaves`. Роли `hr`, `admin`. Больничный не согласуется — его регистрирует HR.

**Ради чего открывают:** зарегистрировать/продлить/закрыть больничный и не пропустить последствия (отпуск по ст. 124, замещение, документы).

## Список

```
Больничные                                               [+ Открыть больничный]
⚠ 2 пересечения с отпуском ждут решения                          [Показать]
[Открытые · 4] [Закрытые за 30 дн.] [Все]           [🔍 ФИО]  [Подразделение ▾]

│ (ИП) Иванов Пётр · ИТ   │ ♥ с 20 нояб. · 6-й день · выход неизвестен │ ЭЛН 9100 0012 3456 │ Зам. нет ⚠ │ [Продлить] [Закрыть] ▾│
│ (СМ) Сидорова М. · Бух. │ ♥ 18–27 нояб. (продлён) · до 27 нояб.     │ ЭЛН …              │ Зам. Орлова ✓│ ⚠ Отпуск с 24 нояб. │
```

- Сортировка по умолчанию: пересечения без решения → без заместителя → открытые давнее сверху.
- В строке: человек, период + «N-й день» для открытых, «выход неизвестен» если `end = null`, ЭЛН моноширинно с группировкой по 4, заместитель, бейджи рисков.
- Действия из строки: «Продлить», «Закрыть». `▾` — детали: история продлений (каждый ЭЛН с датами), пересечения, документы на сотруднике.

## Шит «Открыть больничный»

```
Открыть больничный                                                ✕
Сотрудник    [(ИП) Иванов Пётр — ИТ-отдел ▾]
Начало       [25.11.2026]  (сегодня)
Окончание    [✓] Дата окончания неизвестна   (иначе — поле даты)
Номер ЭЛН    [____ ____ ____]  12 цифр
┌ Что это задевает ─────────────────────────────────────────────────┐
│ ⚠ Согласованный отпуск 1–14 дек. пересекается или скоро начнётся. │
│   Если больничный продлится после 30 нояб., отпуск нужно продлить  │
│   или перенести (ст. 124 ТК РФ). Решение — при закрытии больничного.│
│ 📄 2 этапа документов ждут Иванова: Договор №Д-142 (срок 27 нояб.)│
│   → будут предложены инициаторам для передачи заместителю.         │
│ ⚠ Постоянного заместителя нет.  [Назначить: ▾ ]                     │
└────────────────────────────────────────────────────────────────────┘
                                         [Отмена] [Открыть больничный]
```

- «Что это задевает» появляется после выбора сотрудника и дат: отпуска в периоде (или начинающиеся в ближайшие 14 дней при открытом больничном), этапы документов, заместитель. Ничего нет → «Пересечений нет, заместитель — Смирнов А.» (success).

## Пересечение с отпуском (ст. 124)

Показывается плашкой на строке и в деталях:

```
⚠ Больничный 18–27 нояб. пересекается с отпуском 24 нояб. – 7 дек. на 4 дня.
  По ст. 124 ТК РФ отпуск продлевается на эти дни или переносится по согласованию с сотрудником.
  [Продлить отпуск до 11 дек.]  [Перенести…]  [Решить позже]
```

- «Продлить» — считает новую дату окончания с учётом праздников (ст. 120) и показывает её на кнопке; тост с «Отменить».
- «Перенести…» — открывает форму заявки на перенос неиспользованных дней (тип «Ежегодный», дни предзаполнены).
- Пока больничный открыт, точное число дней неизвестно: «пересекается минимум на 3 дня (больничный открыт)» и кнопка «Продлить» недоступна с тултипом «Станет доступно после закрытия больничного».

## Продлить / Закрыть

- **Продлить** — поповер: новый номер ЭЛН (опц.), новая ожидаемая дата или «Неизвестна». Статус → «Продлён».
- **Закрыть** — ConfirmDialog: дата окончания (по умолчанию сегодня, не раньше начала), итог «Больничный 20 нояб. – 1 дек., 12 календ. дней», последствия: «Отпуск 1–14 дек. продлить на 1 день?» с чекбоксом по умолчанию включён. Статус → «Закрыт».

## Состояния

| Состояние                                 | Что показываем                                                                                                                                                             |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Нет открытых                              | `EmptyState` «Открытых больничных нет» + «Открыть больничный»                                                                                                              |
| Загрузка                                  | 4 скелетон-строки                                                                                                                                                          |
| Ошибка списка                             | `ErrorState` + «Повторить»                                                                                                                                                 |
| Открытый, без даты окончания              | «выход неизвестен», полоса в календаре растворяется                                                                                                                        |
| Без заместителя                           | danger «Нет замещающего» + «Назначить» в строке                                                                                                                            |
| Пересечение не решено                     | warning-плашка, счётчик в навигации                                                                                                                                        |
| Валидация                                 | ЭЛН не 12 цифр; начало в будущем > 3 дней; окончание раньше начала; пересечение с другим больничным того же сотрудника («Уже открыт больничный с 20 нояб. — продлите его») |
| Сохранение / ошибка                       | Спиннер в кнопке; «Не удалось сохранить — повторите», данные формы сохранены                                                                                               |
| Нет доступа (роль сотрудник/руководитель) | Пункта в навигации нет; прямой переход → `ProtectedRoute` на «Сегодня» с тостом                                                                                            |
