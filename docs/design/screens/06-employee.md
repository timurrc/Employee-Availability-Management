# 06. Сотрудник

Код: `src/pages/EmployeePage`. Роут `/employees/:id`. Все роли.

**Ради чего открывают:** «Когда будет на месте и кто за него сейчас?» — вход из поиска (⌘K), из любого `PersonChip`, из таймлайна.

## Структура

```
‹ Назад
(ЕК 56) Егорова Ксения Андреевна                                [Написать ↗]
        Юрист · Юридический отдел · Руководитель: (ОН) Орлов Н.
┌ Сейчас ─────────────────────────────────────────────────────────────┐
│ 🌴 В отпуске до 9 дек. включительно · выйдет 10 дек. (четверг)        │
│ Замещает: (СА) Смирнов Андрей — На месте                             │
│ Постоянный заместитель: (СА) Смирнов А.                    [Изменить]│
└──────────────────────────────────────────────────────────────────────┘
[ План | История ]
 План:  🌴 Отпуск 15–28 февр. 2027 · 14 дн. · На согласовании
        ✈ Командировка 3–5 марта · Согласована
 История: …
┌ Отпуск ──────────────┐ ┌ Документы на нём ────────────────────────┐
│ Доступно 12 дн.      │ │ Договор №Д-142 — этап ждёт, срок 2 дек. ⚠ │
│ использовано 16 из 28│ │ (видно инициатору/руководителю)           │
└──────────────────────┘ └───────────────────────────────────────────┘
```

- **Шапка:** Avatar 56, ФИО полностью, должность · отдел · руководитель (`PersonChip inline`). Действие «Написать» — `mailto:` (вторичное).
- **«Сейчас»** — главный блок, всегда первый. Варианты:
  - на месте → «На месте» (success) + «Следующее отсутствие: с 15 февр. — отпуск» если есть;
  - отсутствует → тип, последний день, дата выхода (ближайший рабочий день после!), заместитель с его статусом;
  - открытый больничный → «Больничный с 20 нояб., дата выхода неизвестна» + номер ЭЛН (только HR);
  - нерабочий день → «Сегодня нерабочий день» + статус на ближайший рабочий.
- **Постоянный заместитель** — с кнопкой «Изменить» (сам сотрудник, его руководитель, HR). Выбор — комбобокс сотрудников со статусами; запрет циклов: если выбор создаёт цикл, опция с пометкой «Создаст цикл: Смирнов → Егорова» и недоступна.
- **План / История** — вкладки; план по умолчанию. Строка: `AbsenceTag` + период + дни + статус. Отклонённые/отменённые — только в истории.
- **Отпуск** (видят сам, руководитель, HR): баланс — тот же блок, что на экране «Отпуска».
- **Документы на нём** — этапы, где он согласующий и которые ещё не решены (видят инициаторы этих документов, руководитель, HR).

## Состояния

| Состояние                    | Что показываем                                                                                                      |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Загрузка                     | Скелетон шапки + блока «Сейчас»                                                                                     |
| Не найден                    | `EmptyState` «Сотрудник не найден» + «К списку команды»                                                             |
| Нет плана/истории            | «Отсутствий не запланировано» / «Истории пока нет»                                                                  |
| Нет постоянного заместителя  | warning «Постоянный заместитель не назначен — при отсутствии документы будут ждать» + «Назначить» (если есть права) |
| Заместитель тоже отсутствует | «Замещает: Козлов Д. (Смирнов в отпуске до 12 дек.)»                                                                |
| Нет замещающего              | danger-тег + «Назначить на период» (руководитель/HR)                                                                |
| Нет прав на баланс/ЭЛН       | Блоки не рендерятся (не «скрыто»)                                                                                   |
| Ошибка                       | `ErrorState` по блоку                                                                                               |
