# 00. Каркас, навигация и демо-вход

Код: `src/components/layouts/MainLayout`, `src/components/modules/Header` → заменяется на `Sidebar` + `Topbar`, `src/components/modules/AccountSwitcher`, `src/pages/LoginPage`.

## Каркас (MainLayout)

Было: горизонтальная шапка с 7 разделами (на узких экранах — горизонтальный скролл). Сделал боковую панель: 7 разделов и роль не помещаются в строку, а сайдбар даёт группы по задачам и место для текущего пользователя.

```
┌──────────────┬──────────────────────────────────────────────────────┐
│ ◧ Доступность│  [🔍 Найти сотрудника…        ⌘K]          [◐ тема] │ ← Topbar 56
│              ├──────────────────────────────────────────────────────┤
│ РАБОТА       │                                                      │
│ ☀ Сегодня    │   Заголовок страницы             [Главное действие] │
│ 📄 Документы 1│                                                      │
│ ⏱ Сроки      │   Контент                                            │
│ ЛЮДИ         │                                                      │
│ ▦ Команда    │                                                      │
│ 🌴 Отпуска  3 │                                                      │
│ ♥ Больничные │                                                      │
│ НАСТРОЙКИ    │                                                      │
│ 📅 Календарь  │                                                      │
│              │                                                      │
│ ─────────────│                                                      │
│ (ИВ) Иванова │                                                      │
│ Руководитель▾│  ← AccountSwitcher                                   │
│ «Свернуть ‹» │                                                      │
└──────────────┴──────────────────────────────────────────────────────┘
```

- **Сайдбар 240 px**, фон `surface`, граница справа `border`. Заголовки групп — `text-xs` 500 uppercase `text-subtle`, отступ 16 сверху.
- **Пункт:** высота 36, иконка 20 + подпись `text-base`; активный — фон `primary-soft`, текст и иконка `primary`, вес 500; hover — `surface-2`. Счётчик справа — `radius-full`, `surface-2`, `text-sm` 500 (не красный).
- **Лого** «Доступность» (рабочее имя, ❓ финальное — вопрос к пользователю) — `text-md` 600 + квадратная иконка 24 (`CalendarCheck` в `primary`).
- **AccountSwitcher внизу:** аватар 32 + ФИО + роль. Клик → меню: список демо-учёток (аватар, ФИО, роль, отметка текущей), разделитель, «Тема: Системная / Светлая / Тёмная», «Сбросить демо-данные», «Выйти». Переключение роли — без перезагрузки; на время — спиннер на аватаре, сайдбар и контент перерисовываются, если текущий раздел недоступен новой роли — переход на «Сегодня» с тостом «Раздел «Больничные» доступен HR — открыли «Сегодня»».
- **Topbar:** поиск сотрудника (комбобокс: результаты — `PersonChip row` со статусом на сегодня, Enter → карточка сотрудника), справа — переключатель темы (иконка). Заголовок страницы — в контенте, не в топбаре.
- **Демо-лента** над контентом не нужна: «Демо» указано в меню аккаунта и на экране входа.

Состояния:

| Состояние                        | Поведение                                                                                                                                                |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Развёрнут (≥ 1280)               | 240 px, по умолчанию                                                                                                                                     |
| Свёрнут (по кнопке или 768–1279) | 64 px, только иконки, тултип справа с подписью и счётчиком; счётчик — точка на иконке. Выбор сохраняется в localStorage (`eam:ui:sidebar`).              |
| Мобильный (< 768)                | Топбар: бургер · название раздела · поиск (иконка). Бургер → панель слева на 85% ширины, затемнение фона, закрытие по тапу вне, свайпу, `Esc`, переходу. |
| Переключение роли                | Спиннер на аватаре в меню, пункты меню заблокированы ≤ 1 с                                                                                               |
| Ошибка загрузки профиля          | Полноэкранный `ErrorState` «Не удалось загрузить профиль» + «Повторить» / «Выйти»                                                                        |
| Загрузка страницы (lazy)         | Каркас остаётся, в контенте `PageLoader` — скелетон заголовка + 3 строки                                                                                 |

## Демо-вход (LoginPage)

Задача: за 5 секунд понять, что это демо, и выбрать, за кого смотреть.

```
            ◧ Доступность
     Модуль доступности сотрудников для СЭД
  Демо: данные вымышленные и хранятся в этом браузере.

  Войти как
  ┌───────────────────────────────────────────────────┐
  │ (ПА) Петров Алексей · Инженер, ИТ-отдел      Сотрудник →│
  │      Подать отпуск, отправить документ на согласование │
  ├───────────────────────────────────────────────────┤
  │ (ИВ) …  · Руководитель ИТ-отдела          Руководитель →│
  │      Согласовать отпуска, увидеть покрытие отдела       │
  ├───────────────────────────────────────────────────┤
  │ HR …                                          HR →      │
  │ Админ …                                  Администратор →│
  └───────────────────────────────────────────────────┘
  С чего начать: войдите руководителем и откройте «Документы» → договор
  с юристом в отпуске.                         [Как устроено — README ↗]
```

- Колонка 480 px по центру, фон `surface`, карточка-список `elevated`, строки 64 px, вся строка — кнопка. ФИО/должность берутся из сотрудника `DEMO_ACCOUNTS[].employeeId`, роль — бейдж справа, `hint` — второй строкой `text-muted`.
- Подсказка «С чего начать» — один рекомендуемый сценарий (ключевой экран).
- Ссылка на README/кейс — вторичная, `text-sm`.

Состояния: загрузка списка — 4 скелетон-строки; вход — спиннер в выбранной строке, остальные заблокированы; ошибка входа — тост «Не удалось войти — повторите» + строка снова активна; сессия истекла — тот же экран с плашкой info «Сессия завершилась — выберите учётную запись».
