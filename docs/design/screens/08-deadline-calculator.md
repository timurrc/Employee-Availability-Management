# 08. Калькулятор сроков

Код: `src/pages/DeadlinesPage`. Роут `/deadlines`. Все роли.

**Ради чего открывают:** «Когда истечёт N рабочих дней от даты?» и «Сколько рабочих дней между датами?» — с объяснением, которому можно доверять.

## Структура

```
Сроки
[ Дата + N рабочих дней | Рабочих дней между датами ]

От   [28.12.2026]  пн        +  [5] рабочих дней
Учитывать отсутствие  [— никого — ▾]  (опционально: сотрудник-исполнитель)

┌ Результат ─────────────────────────────────────────────────────────┐
│ 13 января 2027, среда                                [Копировать]   │
│ 5 рабочих дней = 16 календарных                                       │
│ ▾ Разбор                                                             │
│   29 дек. вт  ① рабочий                                              │
│   30 дек. ср  ② рабочий                                              │
│   31 дек. чт  — нерабочий (перенос с 4 янв.)                          │
│   1–8 янв.    — новогодние каникулы и Рождество                      │
│   9–10 янв.   — выходные                                             │
│   11 янв. пн  ③   12 янв. вт ④   13 янв. ср ⑤                         │
│ Отсчёт со следующего дня после даты «От».                            │
└──────────────────────────────────────────────────────────────────────┘
Мини-календарь двух месяцев: дни отсчёта отмечены номерами, нерабочие — по легенде.
```

- **Результат** — дата крупно (`text-lg`) + день недели, ниже соотношение рабочих/календарных. Разбор раскрыт по умолчанию на десктопе: подряд идущие нерабочие дни схлопываются в один интервал с причиной.
- **Правило отсчёта** написано под разбором явно (со следующего дня; если в ядре будет выбрано иное — текст меняется вместе с правилом). ❓ Подтвердить в этапе 1 (`deadline.ts`).
- **Учитывать отсутствие** (опц.): выбор сотрудника → если он отсутствует в интервале, второй результат: «С учётом отпуска Егоровой (до 9 дек.): 18 дек. или передать Смирнову А. — 2 дек.». Это связывает калькулятор с главной темой.
- **Режим «между датами»:** две даты → «12 рабочих дней · 95 часов (с учётом сокращённого 30 дек.)» + разбор по месяцам.
- Параметры в URL (`?from=2026-12-28&days=5`) — ссылкой можно поделиться. Пересчёт мгновенный, без кнопки «Посчитать».
- Отрицательное N («за 5 рабочих дней до») — поддерживается: «−5».

## Состояния

| Состояние                         | Что показываем                                                                                                                    |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Пусто (первый вход)               | Дата = сегодня, N = 5 — результат сразу (пример лучше пустоты)                                                                    |
| Ошибка ввода                      | N не целое / 0 / > 365; несуществующая дата — inline под полем                                                                    |
| Дата «От» — нерабочий день        | info «28 дек. — рабочий» / «31 дек. — нерабочий: отсчёт начнётся с 11 янв.»                                                       |
| Нет праздников в интервале        | Разбор свёрнут: «Праздников и переносов нет, только выходные»                                                                     |
| Календарь не загружен             | warning «Календарь на 2028 не загружен — праздники не учтены, результат может быть неточным» + результат с пометкой «по выходным» |
| Исполнитель с открытым больничным | «Дата выхода неизвестна — посчитать с учётом отсутствия нельзя. Заместитель: …»                                                   |
| Загрузка календаря                | Скелетон блока результата                                                                                                         |
