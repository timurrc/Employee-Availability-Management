# 01. Сегодня (главная)

Код: `src/pages/HomePage`. Роут `/`. Все роли.

**Ради чего открывают:** «Кого сегодня нет и к кому идти вместо него?» + «Что ждёт моего действия?». Действия — выше сводки.

## Структура (сверху вниз)

```
Сегодня, среда 25 ноября                                  [+ Заявка на отпуск]
Рабочий день · 8 ч. Ближайший нерабочий: 31 дек.        ← строка контекста

┌ Ждут вашего действия ───────────────────────────────────────────────┐
│ 🌴 3 заявки на отпуск ждут решения               [Разобрать →]       │  (руководитель)
│ 📄 Договор №Д-142: юрист в отпуске, этап стоит  [Передать заместителю]│  (инициатор)
│ ♥ Больничный Сидорова пересекается с отпуском    [Решить →]          │  (HR)
└──────────────────────────────────────────────────────────────────────┘

Отсутствуют сегодня · 5                [Мой отдел | Все]   [поиск по ФИО]
┌──────────────────────────────────────────────────────────────────────┐
│ (ЕК) Егорова Ксения · Юрист      🌴 Отпуск до 9 дек.  Замещает (СА) Смирнов А.│
```

## Блоки

1. **Заголовок + контекст дня.** Дата словами; тип дня по производственному календарю (рабочий / сокращённый «7 ч, предпраздничный» / нерабочий). Главное действие: «Заявка на отпуск» (сотрудник, руководитель); у HR — «Открыть больничный»; у админа — нет кнопки.
2. **«Ждут вашего действия»** — показывается, только если есть что делать (не пустая карточка). Макс. 5 строк, остальное — «Ещё 4». Каждая строка = одно действие. Источники по ролям:
   - все: мои документы, где текущий/следующий этап на отсутствующем без передачи → «Передать заместителю» (выполняется прямо здесь, тост с «Отменить»); мои заявки, отклонённые за 7 дней → «Изменить даты»;
   - руководитель: заявки на согласовании → «Разобрать»; дни с покрытием ниже порога в ближайшие 14 дней;
   - HR: пересечения больничных с отпуском без решения; открытые больничные без заместителя.
3. **«Отсутствуют сегодня»** — главный блок. Строка = `PersonChip row` + `AbsenceTag` (тип, «до …» последний день) + `DeputyHint`. Сортировка: «Нет замещающего» сверху, затем по дате выхода. Переключатель «Мой отдел / Все» (у сотрудника по умолчанию «Мой отдел», у HR/админа — «Все»). Поиск по ФИО фильтрует список на месте. Клик по строке → карточка сотрудника.
   - Под списком — свёрнутая группа «Скоро отсутствуют (7 дней)»: тот же формат, тег «С 1 дек. — отпуск».
4. **Покрытие по подразделениям** — `CoverageMeter` на сегодня; строки ниже порога — сверху. Клик → Календарь команды с фильтром по отделу. Сотрудник видит только свой отдел.
5. **Мои ближайшие события (30 дней)** — мои сроки по этапам документов, мои отсутствия, ближайшие нерабочие/сокращённые дни. Хронологически, дата слева колонкой.

Мобильный: блоки в одну колонку в том же порядке; строка «Отсутствуют» — две строки (человек / тег + заместитель).

## Состояния

| Состояние                 | Что показываем                                                                                                                                               |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Загрузка                  | Скелетоны: 2 строки в «Ждут», 4 строки в «Отсутствуют», 3 полосы покрытия. Заголовок и дата — сразу (не зависят от API).                                     |
| Все на месте              | Блок «Отсутствуют» → `EmptyState` с иконкой `CheckCircle` (`success`): «Сегодня все на месте» + строка «Ближайшее отсутствие: Петров, с 1 дек.» (если есть). |
| Нечего делать             | Блок «Ждут вашего действия» не рендерится.                                                                                                                   |
| Ничего не найдено поиском | «Никто с именем «Петр» сегодня не отсутствует» + «Сбросить поиск». Подсказка: «Найти в справочнике (⌘K)».                                                    |
| Нет замещающего           | В строке `danger`-тег «Нет замещающего» + у руководителя/HR действие «Назначить». Строка поднимается наверх.                                                 |
| Цепочка замещения         | «Замещает Козлов Д. (Смирнов тоже отсутствует)» — тултип с цепочкой.                                                                                         |
| Открытый больничный       | Тег «Больничный, выход неизвестен»; дату не выдумываем.                                                                                                      |
| Нерабочий день сегодня    | Контекст «Нерабочий день — 31 дек. (перенос)»; блок «Отсутствуют» показывает то же, но заголовок «Отсутствуют в ближайший рабочий день, 11 янв.».            |
| Ошибка блока              | Ошибка изолирована в блоке: «Не удалось загрузить отсутствия» + «Повторить»; остальные блоки работают.                                                       |
| Ошибка всей страницы      | `ErrorFallback` каркаса.                                                                                                                                     |

## Данные

`GET /absences?date=today`, `/employees`, `/departments`, `/calendar/:year`, `/documents?mine`, `/vacations?status=pending` (руководитель). Расчёты: `statusOn`, `resolveDeputy`, покрытие — `src/core/availability.ts`.
