# 07. Документ и маршрут согласования (демо-СЭД) — ключевой экран

Код: `src/pages/DocumentsPage` (`/documents`), `src/pages/DocumentPage` (`/documents/:id`). Все роли.

**Ради чего открывают:** инициатор — отправить документ так, чтобы он не завис, и знать дату решения; согласующий — увидеть, что ждёт его.

Ключевой вывод в этом экране: **согласующий в маршруте — не строка справочника, а человек со статусом на даты своего этапа.**

## Список документов

```
Документы                                                   [+ Новый документ]
[Мои | Жду моего решения · 1 | Все]   [Статус ▾] [Тип ▾] [🔍 номер, название]
│ №Д-142 Договор поставки ООО «Ромашка» │ На согласовании · этап 2 из 3 │ Сейчас у (ЕК) Егоровой 🌴 до 9 дек. ⚠ Риск срока │ Решение ≈ 14 дек. │
│ №П-031 Приказ об отпусках             │ Черновик                     │ —                                  │ —                 │
│ №С-207 Счёт № 512                     │ Согласовано 20 нояб.         │                                    │                   │
```

- Колонка «Сейчас у» — `PersonChip row` текущего согласующего с его статусом; риск — warning-тег. Это главная информация списка: у кого документ и не застрял ли.
- «Решение ≈» — ожидаемая дата окончания последнего этапа (по `deadline.ts`).

## Документ: структура

```
‹ Документы
№Д-142 · Договор поставки ООО «Ромашка»                    Черновик
Автор (ПА) Петров А. · создан 25 нояб.
┌ ⚠ 1 согласующий отсутствует в даты своего этапа ──────────────────────┐
│ Егорова К. в отпуске до 9 дек. — замещает Смирнов А.   [Передать заместителю]│
└──────────────────────────────────────────────────────────────────────┘
Маршрут согласования                         Старт: [25.11.2026] (сегодня)
 ① (ОН) Орлов Н. · Руководитель ИТ          3 раб. дня   до 30 нояб. (пн)
    ✓ На месте                                              ▸ разбор
 ② (ЕК) Егорова К. · Юрист                  2 раб. дня   до 2 дек. (ср)  ⚠ Риск срока
    🌴 В отпуске 25 нояб. – 9 дек.
    Замещает (СА) Смирнов А. — на месте     [Передать заместителю]  [Оставить]
 ③ (БИ) Белова И. · Гл. бухгалтер           2 раб. дня   до 4 дек. (пт)
    ✈ Командировка 3–4 дек. — пересекается с этапом
    Замещает (ГО) Гусева О.                 [Передать заместителю]
 [+ Добавить согласующего]
Итог: решение ожидается 4 дек. (пт) · 7 рабочих дней
                                          [Сохранить]  [Отправить на согласование]
```

### Строка этапа

- Номер, `PersonChip row` (ФИО, должность), срок «N раб. дней» (редактируемое число), **дата окончания этапа** (крупнее — это обещание), «▸ разбор» → `DeadlineExplain`.
- Под человеком — статус **на даты этапа**, а не только сегодня: «В отпуске 25 нояб. – 9 дек.», «Командировка 3–4 дек. — пересекается с этапом», «Уходит в отпуск 1 дек. — успеет, если согласует до 30 нояб.».
- **Если отсутствует** — `DeputyHint`: заместитель (по цепочке `resolveDeputy`) со своим статусом + действия:
  - **«Передать заместителю»** (secondary, единственная кнопка-действие в строке) — этап сразу получает `delegatedToId`; в строке: «(СА) Смирнов А. — замещает Егорову К.», ссылка «Вернуть Егоровой». Срок и дата пересчитываются, «Риск срока» уходит. Тост «Этап передан Смирнову А.» + «Отменить».
  - **«Оставить»** (ghost) — осознанно ждать: этап остаётся на Егоровой, срок сдвигается на её выход: «до 14 дек. (+8 раб. дн.: ждёт выхода 10 дек.)», тег «Риск срока» заменяется на нейтральный «Ждёт выхода». Повторно предложение не показывается.
- **Цепочка:** «Смирнов тоже отсутствует до 12 дек. → замещает Козлов Д.» (тултип с цепочкой A → B → C).
- **Нет замещающего** (цепочка пуста или цикл): danger «Нет замещающего» + «Выбрать согласующего» (комбобокс) / «Оставить и ждать выхода (до 14 дек.)». Для открытого больничного: «Ждать выхода» недоступно — «дата выхода неизвестна».
- Порядок этапов — перетаскивание за ручку (и кнопки ↑↓ для клавиатуры), удалить — «×» с «Отменить».

### Баннер над маршрутом

Сводка проблем маршрута одним блоком (warning), с действием «Передать заместителям (2)» — пакетно для всех, где заместитель найден. Нет проблем — баннера нет (не «всё хорошо»-плашка).

### Добавление согласующего

Комбобокс «Найти сотрудника»: каждая опция — `PersonChip row` со статусом **на даты будущего этапа**; отсутствующие не скрыты, но с тегом и заместителем второй строкой: «🌴 до 9 дек. · замещает Смирнов А.» + кнопка в опции «Добавить заместителя вместо». Последние выбранные — сверху.

### После отправки

- Статус «На согласовании», шапка: «Сейчас у Орлова Н. · этап 1 из 3 · до 30 нояб.».
- Этапы: пройденные — «Согласовано 27 нояб.», текущий — `info`, будущие — нейтрально; редактирование маршрута закрыто (кроме передачи будущих этапов заместителю — это остаётся доступным инициатору).
- Если согласующий ушёл на больничный **во время** маршрута — баннер «Белова И. на больничном с 1 дек. — этап 3 под риском» + «Передать заместителю». Это же появляется в «Сегодня → Ждут вашего действия».
- Согласующий (текущий) видит панель «Ваше решение: [Согласовать] [Отклонить]».

## Состояния

| Состояние                      | Что показываем                                                                                                                  |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| Загрузка                       | Скелетон шапки + 3 строки этапов                                                                                                |
| Документ не найден             | `EmptyState` «Документ не найден» + «К документам»                                                                              |
| Маршрут пуст                   | `EmptyState` в блоке: «Добавьте согласующих — мы покажем, кто из них на месте» + «Добавить согласующего»; «Отправить» неактивна |
| Все на месте                   | Нет баннера; под каждым «✓ На месте» `text-muted` (без зелёного шума)                                                           |
| Согласующий отсутствует        | warning-строка + `DeputyHint` (см. выше)                                                                                        |
| Цепочка замещения              | Тултип/строка с цепочкой                                                                                                        |
| Нет замещающего / цикл         | danger, «Выбрать согласующего», «Ждать выхода»                                                                                  |
| Открытый больничный            | «На больничном с 20 нояб., выход неизвестен» — срок не считается, «Ждать» недоступно                                            |
| Передано заместителю           | Строка с «замещает …», «Вернуть»                                                                                                |
| Срок за горизонтом календаря   | «Не можем посчитать дату: календарь на 2028 не загружен» вместо даты                                                            |
| Пересчёт срока                 | Дата заменяется сразу (расчёт локальный), без спиннера                                                                          |
| Отправка / ошибка отправки     | Спиннер в кнопке / плашка «Не удалось отправить — маршрут сохранён» + «Повторить»                                               |
| Документ согласован / отклонён | Шапка success/danger, маршрут только для чтения, у отклонённого — причина и кто отклонил                                        |
| Нет прав на правку (не автор)  | Маршрут только для чтения, подсказки заместителя видны, кнопки передачи нет                                                     |
