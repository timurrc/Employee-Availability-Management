# 05. Производственный календарь

Код: `src/pages/CalendarPage`. Роут `/calendar`. Правка — `admin`; остальные роли — чтение (тот же экран без режима правки).

**Ради чего открывают:** админ — привести год в соответствие с постановлением и проверить норму; остальные — «какие дни нерабочие на новогодних?».

## Структура

```
Производственный календарь                [‹] 2027 [›]     [Импорт JSON] [Экспорт]
Основание: постановление Правительства РФ № 1187 от 17.09.2026

┌ Сводка 2027 ─────────────────────────────────────────────────────────┐
│ Рабочих дней 247 ✓   Выходных и праздничных 118   Норма 40-ч недели 1 970 ч │
│ [Год | I кв | II кв | III кв | IV кв]  ← переключает таблицу по месяцам ниже  │
└──────────────────────────────────────────────────────────────────────┘
┌ Январь ───────────┐ ┌ Февраль ──────────┐ ┌ Март ─────────────┐ ┌ Апрель …
│ пн вт ср чт пт сб вс│ │ … 20⇄ 22 23●      │ │ 5⁻¹  8●           │
│ 15 раб. дн · 120 ч │ │ 20 раб. дн · 159 ч│ │                   │
└────────────────────┘ └───────────────────┘ └───────────────────┘
Легенда: □ рабочий  ▒ выходной  ■ праздник  ⁻¹ сокращённый (−1 ч)  ⇄ перенос
```

- 12 месяцев сеткой 4×3 (≥ 1280), 3×4, 2×6, 1×12 на мобильном. Под каждым месяцем — «раб. дней · часов» (норма 40-ч недели; 36 и 24 — в тултипе).
- Раскраска дней — из `03-foundations.md`. Сегодня — обведено `cal-today`.
- **Сводка** — контрольная сумма: рабочих дней, выходных+праздничных, норма часов (40/36/24). Если число рабочих дней отличается от ожидаемого по источнику — warning «Проверьте: 246 рабочих дней, по постановлению — 247».
- Переключатель квартала показывает таблицу «месяц | календ. дни | рабочие | выходные | норма 40/36/24 ч» под сводкой.

## Правка дня (админ)

Клик по дню → поповер:

```
Вт, 23 февраля 2027
Тип  (•) Праздник ( ) Выходной ( ) Рабочий
[ ] Сокращённый (−1 ч)   [ ] Перенос
Примечание [День защитника Отечества     ]
                               [Отмена] [Применить]
```

- Применение — сразу, тост «23 февр. — праздник. Пересчитано: 2 заявки, 4 этапа документов» + «Отменить».
- Недопустимое: «сокращённый» у нерабочего дня — чекбокс неактивен с тултипом.
- Клавиатура: стрелки по дням, Enter — поповер.

## Импорт JSON

1. «Импорт JSON» → выбор файла (формат `ICalendarYearSource`; ссылка «Пример формата»).
2. Предпросмотр: год, источник, «Изменится 6 дней» — список «дата: было → станет», сводка до/после (рабочих дней 247 → 247).
3. ConfirmDialog «Применить календарь 2028?» → тост.

## Состояния

| Состояние                    | Что показываем                                                                                                                                                          |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Загрузка                     | Скелетон сводки + 12 сеток-плашек                                                                                                                                       |
| Год не загружен (напр. 2028) | `EmptyState` «Календарь на 2028 не загружен. Пока он не загружен, сроки считаются только по выходным.» + админ: «Импорт JSON»; остальные: «Обратитесь к администратору» |
| Чтение (не админ)            | Без поповера правки и импорта; клик по дню — тултип с типом и примечанием                                                                                               |
| Сумма не сходится            | warning в сводке (выше)                                                                                                                                                 |
| Ошибка импорта               | «Файл не похож на календарь: нет поля holidays» / «Год 2026 уже есть — заменить?» / «Дата 2027-02-30 не существует» — со строкой файла, если возможно                   |
| Ошибка сохранения            | Тост, день возвращается в прежнее состояние                                                                                                                             |
