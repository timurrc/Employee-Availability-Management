# 03. Отпуска

Код: `src/pages/VacationsPage`. Роут `/vacations` (вкладки в URL: `?tab=mine|queue|all`). Все роли.

**Ради чего открывают:** сотрудник — подать заявку и проследить статус; руководитель — разобрать очередь; HR — посмотреть все заявки (чтение).

## Вкладки по ролям

| Вкладка             | Сотрудник     | Руководитель              | HR  | Админ |
| ------------------- | ------------- | ------------------------- | --- | ----- |
| Мои отпуска         | ✓ (по умолч.) | ✓                         | ✓   | ✓     |
| На согласовании · N | —             | ✓ (по умолч., если N > 0) | —   | —     |
| Все заявки          | —             | свой отдел                | ✓   | ✓     |

## Вкладка «Мои отпуска»

```
Отпуска                                                   [+ Новая заявка]
┌ Баланс на 25 нояб. ───────────────────────────────────────────────┐
│ 12 дн. доступно        Использовано 16 · Запланировано 14 · Год 28│
│ Начислено 2,33 дн./мес. Часть ≥ 14 дней в этом году: ещё не было ⚠ │
└────────────────────────────────────────────────────────────────────┘
Заявки
│ 🌴 15 февр. – 1 мар. 2027 · 14 дн. · Зам. Смирнов А. │ На согласовании · у Орлова Н. │ […]
│ 🌴 3–9 авг. · 7 дн.                                   │ Согласована                    │
│ 🌴 1–5 июня · 5 дн.                                   │ Отклонена: «Сдача проекта»  [Изменить даты]│
```

- **Баланс** — ключевое значение `text-lg`: «12 дн. доступно». Ниже `text-sm`: использовано / запланировано (pending+approved будущие) / годовое право. Пояснение начисления — в тултипе «Как считается»: 28 дн./12 = 2,33 за полный месяц работы.
- Если в рабочем году ещё не было части ≥ 14 дней — warning-строка «Одна из частей отпуска должна быть не меньше 14 дней (ст. 125 ТК РФ)». Не запрет.
- **Заявки** — список (не таблица на мобильном): тип, период, дни, заместитель, статус; у pending — «у кого» (руководитель); у rejected — причина + «Изменить даты» (открывает форму с этими датами). Меню «…»: «Отменить заявку» (pending/approved в будущем), «Удалить» (draft).

## Форма «Новая заявка» (правая панель-шит 480 px, на мобильном — полный экран)

Порядок — как в `CLAUDE.md`: период → расчёт → конфликты → заместитель → отправка. Каждый следующий блок появляется, когда есть данные для него (не заставляем выбирать заместителя до дат).

```
Новая заявка на отпуск                                            ✕
Тип  (•) Ежегодный оплачиваемый  ( ) Без сохранения  ( ) Учебный
Период  [15.02.2027] — [01.03.2027]    или  [14] календарных дней
  ┌ DateRangePicker: февраль | март, праздники/выходные раскрашены ┐
┌ Расчёт ────────────────────────────────────────────────────────┐
│ 14 дней спишется с баланса  →  останется 0 дн.                  │
│ Окончание 1 мар., выход на работу 2 мар. (вт)                    │
│ ▸ Почему 1 марта: 23 февр. — праздник, в отпуск не входит и     │
│   продлевает его (ст. 120). 22 февр. — перенесённый выходной,    │
│   входит в отпуск.                                               │
└─────────────────────────────────────────────────────────────────┘
⚠ В ИТ-отделе 22–26 февр. будет доступно 3 из 6 (50%), порог 60%.
  Тоже отсутствуют: (ПА) Петров — отпуск 20–28 февр.; (КД) Козлов — командировка 24–26 февр.
  Руководитель увидит это предупреждение. Отправить можно.
Заместитель  [(СА) Смирнов Андрей — постоянный ▾]   ✓ На месте в эти даты
Комментарий  [                                     ]
                       [Сохранить черновик]  [Отправить руководителю]
```

- Режимы ввода периода: «с — по» или «с + N календарных дней» (переключатель); второй — для тех, кто знает «хочу 14 дней».
- **Расчёт** обновляется мгновенно; разбор свёрнут, если праздников нет («14 календарных дней, праздников нет»).
- **Конфликт покрытия** — warning-блок, с кем пересекается (`PersonChip inline`), минимум по дням. Не блокирует.
- **Заместитель** — по умолчанию постоянный; его статус на даты заявки рядом. Если он отсутствует в эти даты — warning «Смирнов в отпуске 20–24 февр. — выберите другого или замещение пойдёт к Козлову (цепочка)».
- **Отправка:** primary «Отправить руководителю» (подпись с ФИО руководителя под кнопкой: «Согласует Орлов Н.»). После — шит закрывается, тост «Заявка отправлена Орлову Н.», заявка наверху списка со статусом «На согласовании».

### Состояния формы

| Состояние                                | Поведение                                                                                                                                                                   |
| ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Даты не выбраны                          | Блоки расчёта/конфликтов/заместителя не показаны; кнопка отправки неактивна с подсказкой «Выберите период»                                                                  |
| Ошибка ввода                             | Конец раньше начала; дата в прошлом; > 1 года вперёд; пересечение со своей заявкой («Пересекается с вашим отпуском 3–9 авг.») — inline под полем, `danger`                  |
| Не хватает баланса                       | warning «Не хватает 2 дн.: доступно 12, нужно 14» + действия «Сократить до 12» / «Оформить 2 дн. без сохранения» (вторая заявка). Отправить можно — решает руководитель/HR. |
| Часть < 14 дн. и большой ещё не было     | info «Одна из частей должна быть ≥ 14 дней. Останется 28 − 7 = 21 день — успеете» / или warning, если уже не успеть                                                         |
| Праздник внутри                          | Разбор раскрыт по умолчанию                                                                                                                                                 |
| Конфликт покрытия                        | warning-блок (выше)                                                                                                                                                         |
| Заместитель недоступен / нет заместителя | warning / danger «Нет замещающего — документы будут ждать» + «Выбрать»                                                                                                      |
| Календарь года не загружен               | warning «Календарь на 2028 не загружен — праздники не учтены»                                                                                                               |
| Отправка                                 | Спиннер в кнопке, форма заблокирована                                                                                                                                       |
| Ошибка отправки                          | Плашка в шите «Не удалось отправить — данные сохранены в черновик» + «Повторить»                                                                                            |
| Закрытие с изменениями                   | Диалог «Сохранить черновик?» — «Сохранить» / «Не сохранять»                                                                                                                 |

## Вкладка «На согласовании» (руководитель)

```
На согласовании · 3                              Сортировка: по дате начала ▾
│ (ИВ) Иванова · 8–19 дек. · 12 дн. │ Зам. Смирнов ✓ │ Покрытие ▓▓▓▓░│░ 4 из 6  │ [Согласовать] [Отклонить] ▾│
│ (ПА) Петров · 20–28 февр. · 9 дн. │ Зам. Козлов ⚠ в команд. │ ▓▓▓░│░░ 3 из 6 ⚠ ниже порога│ [Согласовать] [Отклонить] ▾│
Решены сегодня · 2  ▸
```

- Строка содержит всё для решения: человек, период, дни, заместитель со статусом, **минимальное покрытие отдела в период заявки** (если её согласовать). Ниже порога — `danger` и строка сортируется вверх.
- «Согласовать» — сразу, тост с «Отменить» 5 с. «Отклонить» — поповер с обязательной причиной (быстрые варианты: «Пересечение с отпусками команды», «Проектный срок», свой текст).
- `▾` раскрывает строку: мини-таймлайн отдела на период заявки ±3 дня (компонент из Календаря команды), комментарий сотрудника, баланс сотрудника, предупреждения, которые видел сотрудник.
- Пакетно: чекбоксы + «Согласовать выбранные (2)» — только для строк без конфликтов (чекбокс у конфликтных отключён с тултипом).

| Состояние                                 | Что показываем                                                                  |
| ----------------------------------------- | ------------------------------------------------------------------------------- |
| Пусто                                     | `EmptyState` `CheckCircle` «Все заявки разобраны» + «Открыть календарь команды» |
| Загрузка                                  | 3 скелетон-строки                                                               |
| Решение отправляется                      | Строка с полупрозрачностью и спиннером в кнопке                                 |
| Ошибка решения                            | Строка возвращается, тост «Не удалось согласовать — повторите»                  |
| Заявка отменена сотрудником, пока открыта | Строка серая «Сотрудник отменил заявку» и исчезает при обновлении               |

## Вкладка «Все заявки» (HR, руководитель — отдел)

Таблица с фильтрами: подразделение, статус, тип, период. Колонки: сотрудник, тип, период, дни, статус, заместитель, создана. Только чтение для HR (HR не согласует отпуска). Пусто по фильтру — «Сбросить фильтры».
